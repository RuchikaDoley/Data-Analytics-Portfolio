Netflix Content Analysis | Tableau

Seven Tableau views exploring Netflix's catalogue of movies and TV shows. Open `netflix_content_analysis.twbx` in Tableau Desktop or Tableau Public. The data is packaged inside the file.

Data:
The Netflix Titles dataset (CSV). Each row is a title, with these fields: Show Id, Type, Title, Director, Cast, Country, Date Added, Release Year, Rating, Duration, Listed In (genres) and Description.

What I did:
- Connected the Netflix Titles CSV in Tableau and created an extract.
- Split the Listed In field into separate genres so each genre could be analysed on its own.
- Built seven views looking at the catalogue by genre, country, release year, content type (movie or TV show) and rating.

What the views help answer:
- Which genres and countries produce the most titles
- How the number of titles changed by release year
- How the catalogue splits between movies and TV shows
- Which ratings are most common
